# گلد بات تریدر — ربات هوشمند معامله طلا، بیت‌کوین و یورو

اپلیکیشن وب (PWA) معامله خودکار با هوش مصنوعی + اتصال به MetaTrader 5 از طریق MetaApi.

## ساختار پروژه

```
├── src/                        ← رابط کاربری Next.js (فارسی، RTL، تم تیره و طلایی)
├── mini-services/trading-engine/  ← موتور معامله (Bun) — بازار، AI، ریسک، MT5
├── public/                     ← آیکون‌ها و مانیفست PWA
├── prisma/                     ← اسکیمای دیتابیس (اختیاری)
└── package.json
```

## راه‌اندازی

پیش‌نیاز: نصب [Bun](https://bun.sh) — `curl -fsSL https://bun.sh/install | bash`

```bash
# ۱) نصب وابستگی‌های رابط کاربری
bun install

# ۲) اجرای موتور معامله (ترمینال جدا — پورت 3003)
cd mini-services/trading-engine
bun install
bun index.ts

# ۳) اجرای رابط کاربری (ترمینال دیگر — پورت 3000)
cd ../..
bun run dev
```

سپس در مرورگر موبایل یا دسکتاپ: `http://localhost:3000`

## نصب روی اندروید (PWA)

۱. سایت را با HTTPS باز کنید (مثلاً از طریق هاست یا تونل).
۲. منوی مرورگر ← «افزودن به صفحه اصلی / Add to Home Screen».
۳. اپ مثل یک برنامه مستقل تمام‌صفحه اجرا می‌شود.

## اتصال حساب واقعی MT5

۱. در سایت `metaapi.cloud` حساب رایگان بسازید.
۲. حساب MT5 بروکر خود را به MetaApi اضافه و Deploy کنید.
۳. در تنظیمات برنامه: توکن Personal Token و شناسه حساب را وارد کنید.
۴. دکمه «تست اتصال» را بزنید — اگر موفق بود، حالت را روی MT5 بگذارید.
۵. حد ضرر/حد سود (پیپ) و حجم لات را تنظیم کنید.

> قفل ایمنی: تا وقتی اتصال MT5 برقرار نباشد، موتور هیچ سفارش واقعی ثبت نمی‌کند.

## ویژگی‌ها

- تحلیل AI با مدل GLM + فال‌بک تحلیل تکنیکال محلی (RSI، MACD، EMA، ATR، KER)
- اسکنر ۳ بازار: طلا (XAUUSD)، بیت‌کوین (BTCUSD)، یورو/دلار (EURUSD)
- حالت توربو با ۶ زمان بستن خودکار: ۱۵ / ۳۰ / ۴۵ / ۶۰ / ۹۰ / ۱۲۰ ثانیه
- مدیریت ریسک: حد ضرر خودکار، سقف ضرر روزانه، استراحت بعد از باخت، فیوز توقف بعد از ۳ باخت پیاپی، توقف اضطراری
- آمار کامل: نرخ برد، ضریب سود، نمودار رشد سرمایه، عملکرد به تفکیک بازار، خروجی CSV
- حجم خودکار (درصد از موجودی) برای متوازن‌شدن رشد حساب
- صدای برد/باخت + لرزش + نوتیفیکیشن

## هشدار ریسک

معامله در بازار طلا و فارکس با ریسک بالای از دست دادن سرمایه همراه است. عملکرد گذشته تضمینی برای آینده نیست. ابتدا با حساب دمو تمرین کنید؛ مسئولیت هر معامله با خود شماست.
